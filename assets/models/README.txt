MODEL IMPORT GUIDE

Included zombie pack:
- zombie-pack.glb
- Automatically separated into 10 zombie variants at runtime.
- Bundled animation clip: Take 001 (about 7.37 seconds).

Optional exact filenames:
- player.glb
- rifle.glb

For a future photorealistic zombie replacement, use GLB with:
- Height around 1.7 to 1.9 metres.
- Origin at ground level between the feet.
- PBR textures packed inside the GLB.
- One armature with separate animation clips named Idle, Walk, Run, Attack and Death.
- A license that permits use and distribution inside a game.

Blender export:
File > Export > glTF 2.0
Format: glTF Binary (.glb)
Enable: Selected Objects, Apply Modifiers, Animation, Skinning
Textures: pack/embed them in the GLB.
